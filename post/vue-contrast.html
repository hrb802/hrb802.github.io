对比文档Vue3 vs Vue2

发表于2026-04-14|更新于2026-04-15|前端
|总字数:4.8k|阅读时长:21分钟|浏览量:

主要来自： Vue 3 迁移指南 一切主要理论按照原文档为准
笔记主要来自原文档，只是在此基础上添加了简单的总结和小举例

全局API

全局API应用实例

CreateApp

调用 createApp 返回一个应用实例，一个 Vue 3 中的新概念。

Vue.prototype ==> config.globalProperties

Vue.prototype 替换为 config.globalProperties

Vue.extend() 移除

先Vue.extend 创建构造器 再用new创建实例

全局 UMD 模式：Vue.createApp(Profile).mount(...) 有效 :

模块化模式（推荐）：必须显式导入 createApp，不能直接写 Vue.createApp

vue3 直接写普通对象，通过Vue.createApp(对象名)。mount(挂载点)

挂载App

Provide / Inject

vue 3 应用实例也提供了可被应用内任意组件注入的依赖项

子组件中直接使用，不需要props

全局 API Treeshaking

tree-shaking 不用的代码，打包时自动扔掉

Vue2：所有 API 绑在 Vue 上，不用也会打包进去

Vue3：API 按需导入，不用就自动删掉（打包更小）

vue2：全部再Vue上，

Vue3：按需导入，导入了什么就打包什么

模板指令

v-model

Vue2 的 v-model、.sync、model 选项全部统一成了 Vue3 的一种写法：v-model: 参数

默认 prop 从 value → modelValue

默认事件从 input → update:modelValue

.sync 被删除了，用 v-model:xxx 代替

（.sync 被 v-model: 参数 替代了）

现在支持 多个 v-model

基础对比

Vue2

  • prop 固定叫：value
  • 事件固定叫：input

问题：

你想用别的名字（比如 title），必须写 model 选项，超级麻烦！

Vue3

prop 固定叫：modelValue

事件固定叫：update:modelValue

sync

废除sync 用v-model:title代替

相当于

多个v-model

key

v-if 分支不用再写 key，Vue 自动给

如果自己写 key，每个分支必须不一样，不能重用
